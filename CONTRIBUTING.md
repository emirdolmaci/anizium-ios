# Katkıda Bulunma Rehberi (Contributing Guidelines) 🤝

Anizium iOS projesine açık kaynak topluluğunun her türlü katkısı (hata bildirimi, özellik önerisi, kod katkısı) memnuniyetle karşılanır.

## Nasıl Katkıda Bulunabilirsiniz?

1. **Depoyu Fork Edin**: Sağ üstteki "Fork" butonuna tıklayarak depoyu kendi hesabınıza kopyalayın.
2. **Dal (Branch) Oluşturun**:
   ```bash
   git checkout -b feature/yeni-ozellik
   ```
3. **Değişikliklerinizi Yapın**: Kod yazım standartlarına (Swift 5, SwiftUI kuralları, YAGNI prensipleri) özen gösterin.
4. **Commit Mesajları**: Conventional Commits standardını (`feat:`, `fix:`, `docs:`, `refactor:`) kullanın.
5. **Pull Request (PR) Açın**: Açıklayıcı bir başlık ve yapılan değişikliklerin özetini içeren PR gönderin.

## Lisans

Projeye gönderdiğiniz tüm katkılar otomatik olarak [MIT Lisansı](LICENSE) kapsamında lisanslanacaktır.
